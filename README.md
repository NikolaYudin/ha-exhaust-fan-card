# 🌀 Exhaust Fan PRO — панель вытяжки для Home Assistant

Панель управления принудительной вытяжкой: hero-блок с крутящимся вентилятором,
кнопки запуска с таймером, умная кнопка продления и живая строка отсчёта
с посекундным тиком. Три блока на экране, ноль лишних настроек: нажал — работает.

## ✨ Возможности

- 🌀 Hero-блок (button-card): крутящийся вентилятор и неоновое свечение при работе
- 🔘 Тап по вентилятору — постоянное включение без ограничения времени
- ⏱ Кнопки 5 / 15 / 30 мин — включение с таймером автоотключения
- ➕ Умная «+5 мин»: выключено → старт как «5 мин»; постоянно → ограничение 5 мин; с таймером → продление
- ⏳ Строка таймера: «осталось ММ:СС · отключится в ЧЧ:ММ», тик каждую секунду, не кликабельна
- 🛑 «Стоп» и ручное выключение сбрасывают таймер
- 🎨 Темизация: поверхности и текст из переменных темы, акцент фиксированный — ничего не пропадает при смене темы
- 🧩 Package-подход: один файл, не ломает `configuration.yaml`, отключается переименованием
- 📊 Посекундный сенсор исключается из recorder — база не раздувается

## 🧩 Требования

- Home Assistant **2024.8+**
- HACS (Frontend): [button-card](https://github.com/custom-cards/button-card)
- Любое on/off-реле (автор использует Tuya switch)

## 🚀 Установка

1. HACS → Frontend → установите **button-card**.
2. Скопируйте `packages/vytyazhka.yaml` в `/config/packages/`.
3. Добавьте один раз в `configuration.yaml`:
   ```yaml
   homeassistant:
     packages: !include_dir_named packages
   ```
4. Защитите базу от посекундных записей (в `configuration.yaml`):
   ```yaml
   recorder:
     exclude:
       entities:
         - sensor.vytyazhka_timer_left
   ```
5. Замените `switch.prinuditelnaia_vytiazhka_switch_1` на entity_id вашего реле
   (в пакете — 4 места, в карточке — 2 места).
6. «Проверить конфигурацию» → перезапуск HA.
7. Дашборд → ⋮ → Редактор кода → вставьте `lovelace/exhaust_card.yaml`.

## ⚙️ Поведение

| Действие | Результат |
|---|---|
| Тап по вентилятору | Постоянное включение, без таймера |
| 5 / 15 / 30 мин | Включение + таймер автоотключения |
| +5 мин | Выкл → старт на 5 мин; постоянно → ограничение 5 мин; с таймером → +5 мин к остатку |
| Стоп / тап при работе | Выключение + сброс таймера |
| Таймер дошёл до 0 | Автоматическое выключение реле |

## 🎨 Кастомизация

| Что крутить | Где | Эффект |
|---|---|---|
| `#00bcd4` | hero, кнопки, строка таймера | цвет акцента |
| `#9aa7b4` | hero → styles → icon | цвет вентилятора в покое |
| `animation: spin 1.2s` | hero → extra_styles/styles | скорость вращения |
| `minutes: 5/15/30` | карточка → кнопки | значения быстрого запуска |

## 🌗 Темы

Поверхности и тексты — из переменных темы (`--ha-card-background`,
`--card-background-color`, `--primary-text-color`, `--secondary-text-color`,
`--ha-card-border-color`, `--divider-color`): карточка нативна и в светлой,
и в тёмной теме. Акцент и цвет вентилятора фиксированные — не «пропадают»
на кастомных темах.
